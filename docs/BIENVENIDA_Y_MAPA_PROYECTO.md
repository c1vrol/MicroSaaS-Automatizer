# Micro-SaaS Scraper Seguro (Prueba de Concepto)

Bienvenido al proyecto de automatización segura. Este repositorio es un ejemplo de cómo construir bots de scraping con estándares de ciberseguridad y calidad corporativa.

## 🚀 Inicio Rápido

1. **Entorno:** Crea tu entorno virtual con `python -m venv .venv`.
2. **Dependencias:** Instala todo con `pip install -r requirements.txt`.
3. **Playwright:** Configura el navegador con `playwright install chromium`.
4. **Secretos:** Copia `.env.example` a `.env` y rellena con tus credenciales seguras.
5. **Ejecutar:** Lanza el script con `python src/main.py`.
